# Hydration and homeostasis tracker
A python based tool that tracks hydration in order to maintain homeostasis in humans

**inputs**
Daily water intake (L)
Body weight (lbs.)
Temperature (F)
Exercise/activity (min)

**outputs**
Estimated hydration level (%)
Hydration status (Hydrated/ Mild Dehydration/ Dehydrated)
suggested water intake
